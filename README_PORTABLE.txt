Face Similarity Checker - Portable Windows x64

Cara menjalankan:
1. Salin seluruh folder FaceSimilarityPortable ke PC Windows x64.
2. Buka folder tersebut dan jalankan "Jalankan Face Similarity.bat".
3. Tunggu browser membuka aplikasi lokal.

Paket ini menyertakan runtime Python, dependency, model ArcFace, model
RetinaFace, dan OpenCV cascade. Python tidak perlu dipasang di PC tujuan.
Aplikasi portable berjalan dalam mode offline dan tidak akan mengunduh aset
yang hilang. Jika ada pesan aset tidak ditemukan, salin ulang seluruh folder.

Jangan memisahkan, mengganti nama, atau menghapus file di dalam folder ini.
Foto yang dipilih diproses secara lokal oleh aplikasi.

Aktifkan "Tampilkan kotak deteksi wajah" di aplikasi untuk memberi kotak pada
wajah yang ditemukan di foto. Deteksi memakai model RetinaFace yang sudah ada
di folder ini; fitur ini hanya membantu tinjauan visual, bukan identifikasi.
